## H2: Why Base Building Matters More Than Ever in 2026

Rust's raiding culture has evolved. With more explosive tools and clan warfare, a poorly designed base is a sitting duck. This guide covers layouts that balance **defense**, **upkeep cost**, and **raid resistance**.

## H2: Understanding Rust's Building System

### H3: Wall Types (Weakest to Strongest)

| Material | HP | Cost | Time to Raid |
|----------|----|------|-------------|
| Wood | 500 | Cheap | 2-3 minutes |
| Stone | 1,000 | Medium | 8-10 minutes |
| Sheet Metal | 2,000 | Expensive | 15-20 minutes |
| Armored | 3,000 | Very expensive | 30+ minutes |

**Recommendation:** Start with **stone**, upgrade key walls to **sheet metal**, save armored for core rooms.

### H3: The Tool Cupboard (TC) — Your Most Important Item

The TC controls building authorization. Without it, anyone can damage your base.

**Golden Rules:**
- Place TC in the **center** of your base
- Ensure TC coverage reaches **every external wall**
- **Lock your TC immediately** — change the code from default 1234!
- Build a TC room with **airlock protection** (2 doors before reaching TC)

## H2: Best Base Layouts for 2026

### H3: Layout 1 — The Classic 2x2 Square

Best for: Solo players, early-game

```
[ Storage ] [ Furnace ]
[   TC    ] [ Repair Bench ]
```

**Pros:** Simple, cheap upkeep, easy to defend
**Cons:** Predictable, vulnerable to systematic raids

### H3: Layout 2 — The Bunker Compound

Best for: Clans (3-5 players)

```
[ Main Base ]
    [ Bunker ] ← Hidden secondary loot
    [ Airfield ] ← Decoy
```

**Pros:** Layered defense, raiders waste explosives on decoy
**Cons:** High upkeep cost

### H3: Layout 3 — The Honeycomb Design

Best for: Protecting high-value loot

```
[ Core Room ]
  [ Halls ] [ Halls ] [ Halls ]
    ↑ Sheet metal honeycomb surrounds core
```

**How it works:** Each honeycomb cell costs explosives to breach. Raiders need to blow through 2-3 cells to reach your core.

**Pro tip:** Use **gates** (not walls) between honeycomb cells — gates cost more to break per use but are cheaper to build.

### H3: Layout 4 — The Roof Camp (Aggressive)

Best for: PvP-focused players

Stack a **high roof tower** (3-4 floors) with 360° sightlines. Add a **staircase of external walls** — attackers must break each wall to reach you.

## H2: Anti-Grief Strategies

### H3: Defensive Layering

The "3-layer defense" approach:
1. **Outer shell:** Stone walls (cheap raiders stop here)
2. **Middle shell:** Sheet metal (mid-tier raiders stop here)
3. **Core:** Armored (only dedicated raiders reach here)

### H3: Misdirection Techniques

- **Fake loot rooms:** Put 1-2k scrap in a visible box outside your TC range
- **Locked external doors:** Use wooden doors on decoy rooms
- **Hidden airlocks:** Don't make your real entrance obvious

### H3: Location-Based Defense

| Monument Near Base | Defense Strategy |
|-------------------|-----------------|
| Large Oil Rig | Expect nightly PvP; build shootable cover |
| Dome | Avoid building inside Dome walls — easy LOS for attackers |
| Outpost | Don't build facing Outpost roads — too exposed |

## H2: Upkeep Calculator

Every building piece costs resources to maintain. If upkeep runs out, walls decay.

### Quick Upkeep Formula

```
Stone wall:  ~10 stone/day
Sheet metal: ~25 metal fragments/day
Armored:     ~75 metal fragments/day
TC:          Covers all pieces within radius
```

**Tip:** Use the **Outpost monument** to buy upkeep-free building privilege with scrap.

## H2: FAQ

**Q: How do I protect my base from offline raids?**
A: You can't fully prevent offline raids. Mitigation: spread loot, hide decoy bases, use locked external walls, and never store all resources in one place.

**Q: Is honeycomb worth the cost?**
A: Yes for protecting high-value loot (C4, explosives, AKs). No for early-game when raiders are unlikely to invest explosives in you.

**Q: How many walls before a TC room?**
A: Minimum 2 walls (airlock) between outside and TC. Use 3-4 for high-value bases.
