## H2: Crosshair Settings — The Most Important Change

Your crosshair is your primary feedback tool. Here's how to set it up:

### H3: Recommended Crosshair Code (Copy-Paste)

Open the console in Valorant and paste this code:

```
crosshairThickness 1
crosshairGap -2
crosshairColor 4
crosshairColorCode r
crosshairOutlines 1
crosshairOutlinesOpacity 0.1
crosshairOutlinesThickness 1
crosshairInnerLinesOpacity 1
crosshairInnerLinesLength 0
crosshairInnerLinesThickness 1
crosshairInnerLinesOffset 0
crosshairFiredAnimation 0
crosshairErrorColor 0
```

### H3: Crosshair Color Guide

| Number | Color | Best For |
|--------|-------|---------|
| 0 | White | General visibility |
| 1 | Green | Best contrast on most maps |
| 2 | Yellow | Bright maps (Ascent, Breeze) |
| 3 | Cyan | Duelist players who need flashy contrast |
| 4 | Red | Clove/Vyse agent players (red maps) |

**Pro recommendation:** Use **Red (4)** if you're on Fade agent or playing Clove. Otherwise, stick to **Green (1)** for maximum contrast.

### H3: Dynamic vs Static Crosshair

- **Static:** Crosshair stays the same regardless of movement/shooting
- **Dynamic:** Crosshair spreads when you move or shoot

**Recommendation:** Start with **Static**. Most pros use static because it provides consistent feedback.

## H2: Mouse Sensitivity Settings

### H3: Pro Sensitivity Reference

| Player | DPI | In-Game Sens | eDPI |
|--------|-----|-------------|------|
| TenZ | 800 | 0.375 | 300 |
| Asuna | 800 | 0.338 | 270 |
| ScreaM | 400 | 0.69 | 276 |
| Derke | 800 | 0.324 | 259 |
| Chronicle | 800 | 0.385 | 308 |

**What is eDPI?** eDPI = DPI × In-Game Sensitivity. Use this to compare settings across different DPIs.

**Recommended eDPI range:** 200-400 (most pros fall in this range)

### H3: How to Find Your Ideal Sensitivity

1. Start with **eDPI 250** (e.g., 800 DPI × 0.312 in-game)
2. Play 50-100 rounds and assess
3. If you're overshooting: lower it by 10-15%
4. If you're undershooting: raise it by 10-15%
5. Fine-tune from there

### H3: Polling Rate

Set your mouse polling rate to **1000Hz** in your mouse software. Higher polling rate = more accurate mouse movement tracking.

## H2: Graphics Settings — Performance vs Clarity

### H3: Recommended Graphics Config for Performance

| Setting | Recommended | Why |
|---------|-------------|-----|
| Display Mode | Fullscreen | Lowest input lag |
| Resolution | Native | Sharpest image |
| Aspect Ratio | Native | Correct proportions |
| Material Quality | Low | Cleaner visuals, less noise |
| Texture Quality | Medium | Fine balance |
| Detail Quality | Low | Better FPS in fights |
| Anti-Aliasing | None or FXAA | FXAA = slight blur for performance |
| Vignette | Off | Adds visual noise, no benefit |
| VSync | Off | Causes input lag |
| NVIDIA Reflex | On + Boost | Reduces system latency |
| Upscaling | Off | Native rendering is sharpest |

### H3: NVIDIA Reflex — Why You Must Enable It

NVIDIA Reflex Low Latency (found in NVIDIA Control Panel + in-game) reduces render queue, giving you up to **10ms lower latency**. Turn it **On + Boost** for competitive play.

### H3: For Low-End PCs

If you're getting below 60 FPS:
- Set everything to Low
- Turn off all anti-aliasing
- Turn off shadows
- Cap FPS at monitor refresh rate via in-game setting

## H2: FAQ

**Q: Should I use VSync in Valorant?**
A: No. VSync adds input lag. If you have screen tearing, use NVIDIA Reflex instead.

**Q: What sensitivity do most Valorant pros use?**
A: Most pros use an eDPI between 200-400. The most common DPI is 800 with 0.3-0.4 in-game sensitivity.

**Q: Is 144Hz monitor required for Valorant?**
A: Not required but highly recommended. 144Hz gives smoother motion and faster visual processing. 60Hz is playable but puts you at a disadvantage.
